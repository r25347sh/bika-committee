## メニュー操作（G5PORTAL 方式）

- **FAB（右下の円ボタン）** … ハンバーガーメニューを開く
- **長押し** または **3回タップ** … ラジアルメニューを表示
- **Esc** … メニューを閉じる

デザインはクリーンな「脱ハウスダスト」テーマ（ミント・ティール系）に変更しています。

## 技術

- HTML / CSS / JS 分離（`css/`, `js/`）
- ラジアル + ハンバーガー FAB（同一操作モデル）
- ハウスダスト風パーティクル（マウス接近で「掃除」される演出）
- スクロールリビールアニメーション
- レスポンシブ対応

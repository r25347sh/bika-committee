## メニュー操作

- **FAB（右下の円ボタン）** … ハンバーガーメニューを開く
- **長押し** または **3回タップ** … ラジアルメニューを表示
- **Esc** … メニューを閉じる

## 技術

- HTML / CSS / JS 分離（`css/`, `js/`）
- ラジアル + ハンバーガー FAB（同一操作モデル）
- ハウスダスト風パーティクル強化版
- スクロールリビール + Magnetic
- レスポンシブ / prefers-reduced-motion 対応
